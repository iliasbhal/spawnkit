<Steps>

<Step>
### Install the Package

Let's start by adding Spawnkit to your project:

```package-install
spawnkit
```

<Callout type="info">
Spawnkit works with any TypeScript or JavaScript project. It's designed to be framework-agnostic.
</Callout>
</Step>

<Step>
### Set Environment Variables

Create a `.env` file in the root of your project and add the following environment variables:

1. **Redis Connection** (optional but recommended for production)

```txt title=".env"
REDIS_URL=redis://localhost:6379
```

2. **Set Base URL** (if using HTTP transport)

```txt title=".env"
SPAWNKIT_URL=http://localhost:3000
```

</Step>

<Step>
### Create Adapters

Create a file named `adapters.ts` in your project to configure how Spawnkit communicates:

```ts title="adapters.ts"
import * as Spawnkit from 'spawnkit';

export function createAdapters() {
  return {
    // For local development, use memory adapter
    transport: new Spawnkit.MemoryTransport(),
    
    // For production, use Redis adapter
    // transport: new Spawnkit.RedisTransport({
    //   url: process.env.REDIS_URL
    // }),
    
    // Optional: Configure persistent storage
    // storage: new Spawnkit.SqliteStorage({
    //   database: './spawnkit.db'
    // })
  };
}
```

<Callout type="info">
For production deployments, we recommend using Redis for communication between instances. The memory adapter works great for local development.
</Callout>
</Step>

<Step>
### Define Your Instances

Create a file to define your instance classes. These are the stateful microservices that Spawnkit will manage.

```ts title="instances.ts"
import * as Spawnkit from 'spawnkit';

// Define a simple instance
export class Counter extends Spawnkit.Instance {
  count = 0;
  
  increment(amount: number = 1) {
    this.count += amount;
    return this.count;
  }
  
  decrement(amount: number = 1) {
    this.count -= amount;
    return this.count;
  }
  
  getCount() {
    return this.count;
  }
}

// Define a more complex instance with streaming
export class EventStream extends Spawnkit.Instance {
  events: string[] = [];
  
  addEvent(event: string) {
    this.events.push(event);
    return this.events.length;
  }
  
  // Example of a streaming method
  subscribeToEvents() {
    return new Spawnkit.Stream<string>(async (stream) => {
      // Send existing events immediately
      for (const event of this.events) {
        stream.emit(event);
      }
      
      // Set up a subscription for future events
      const unsubscribe = this.on('newEvent', (event) => {
        stream.emit(event);
      });
      
      // Return cleanup function
      return () => {
        unsubscribe();
      };
    });
  }
}
```
</Step>

<Step>
### Create Spawnkit Client

Now, create the Spawnkit client that will manage your instances:

```ts title="client.ts"
import * as Spawnkit from 'spawnkit';
import { createAdapters } from './adapters';
import { Counter, EventStream } from './instances';

export const client = Spawnkit.Client.from({
  adapter: createAdapters(),
  instances: {
    Counter,
    EventStream,
  },
});

// Optional: Start the client immediately
// client.start();
```

<Callout type="info">
You can either start the client immediately in your file or start it when your application initializes.
</Callout>
</Step>

<Step>
### Initialize Spawnkit

In your main application file (e.g., `index.ts`, `server.ts`, etc.), initialize Spawnkit:

```ts title="index.ts"
import { client } from './client';

async function main() {
  // Start the Spawnkit client
  await client.start();
  
  // Spawn instances
  const counter = client.spawn("Counter", "main-counter");
  const eventStream = client.spawn("EventStream", "main-events");
  
  // Use the instances
  console.log("Initial count:", await counter.getCount());
  console.log("After increment:", await counter.increment(5));
  
  // Add an event
  await eventStream.addEvent("Application started");
  
  // Example of subscribing to a stream
  const subscription = await eventStream.subscribeToEvents();
  subscription.on("data", (event) => {
    console.log("Event received:", event);
  });
  
  // Your application logic here...
}

main().catch(console.error);
```
</Step>

<Step>
### Using Scheduled Tasks (Optional)

Spawnkit enables you to schedule tasks with flexible timing options:

```ts title="scheduling-example.ts"
import { client } from './client';

async function setupScheduledTasks() {
  // Get an instance
  const counter = client.spawn("Counter", "scheduled-counter");
  
  // Schedule a one-time task to run after 5 seconds
  const oneTimeTaskId = await counter.schedule({ delay: 5000 })
    .increment(10);
  
  // Schedule a recurring task using cron syntax (every 5 minutes)
  const recurringTaskId = await counter.schedule({ cron: "*/5 * * * *" })
    .increment(1);
  
  // Later, if you need to cancel the scheduled tasks:
  // counter.unschedule(oneTimeTaskId);
  // counter.unschedule(recurringTaskId);
}
```

<Callout>
Scheduled tasks persist across instance restarts and can be managed through the instance API.
</Callout>
</Step>

<Step>
### Creating Plugins (Optional)

Spawnkit's plugin system allows you to extend functionality across all instances:

```ts title="plugins-example.ts"
import * as Spawnkit from 'spawnkit';

// Create a simple logging plugin
const loggingPlugin = Spawnkit.createPlugin({
  name: 'logging',
  
  // Hook called before any method execution
  async beforeMethodCall({ instance, methodName, args }) {
    console.log(`Calling ${instance.constructor.name}.${methodName} with args:`, args);
    return { args }; // Return potentially modified args
  },
  
  // Hook called after method execution
  async afterMethodCall({ instance, methodName, result }) {
    console.log(`Method ${instance.constructor.name}.${methodName} returned:`, result);
    return { result }; // Return potentially modified result
  },
});

// Add the plugin to your client configuration
export const client = Spawnkit.Client.from({
  adapter: createAdapters(),
  instances: { /* your instances */ },
  plugins: [loggingPlugin],
});
```
</Step>
